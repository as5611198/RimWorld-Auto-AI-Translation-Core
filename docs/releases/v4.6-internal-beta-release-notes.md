# AI 智能汉化网络 V4.6 内测版说明

发布日期：2026-10-09。群友内测包面向 RimWorld 1.6，沿用 V4.5 内测包安装结构。

## 相比 V4.5 的主要改动

- 新包加入【翻译工作台 → 管理 → 迁移历史数据】：当前语种、已启用 Mod 的旧 XML 译文只补缺导入，全部记为 AI 来源；不调用 AI、不删除旧文件、不预扫总数、不显示百分比。旧 UI 缓存缺少归属信息，本次保留不导入 DLL 条目。历史 XML 未保存原文，迁移报告提示未核对历史原文。

- 首次页面数据库初始化与 Mod 名录同步转入后台，显示进度和同步汇总；处理此前首次点击设置长时间阻塞的问题。
- XML / DLL 分析触发当前语种原生译文收集，记录 Mod、语种和分析状态，复用版本未变且已完成的记录；补齐目标语种缓存和已有译文保护。原生读取失败允许继续 AI 流程，并记录失败。
- 补齐新旧 XML 规则差异及材料名称修饰语等通用字段；未知文本保留待复核候选。
- 修正 DLL 泛型字典键参数追踪，补充已有分析证据到 AI 复核输入；UI 临时采集与 DLL 分析可同时使用。
- 三档 API 路由恢复为批量翻译使用大量档、复核使用中量档、单条补试使用小量档，保留已约定的配置回退逻辑。
- 移除共用响应入口根据英文残留、文字体系、繁简字形或原译文相同拒收译文的判断；保留空值、占位符和格式参数校验。删除若干根据 TODO/none/null 猜测假译文的过滤及清理逻辑。
- 增加调试模式下拒收译文、条目编号映射和异常批次模型输出日志；部分失败不会再被描述为全部失败。
- 试跑预算余量改为 30%；增加每次模型请求的固定提示词和动态内容估算、接口实际输入/输出 Token 调试记录。缓存输入不抵扣。
- 调整热重载耗时警告阈值，减少几十毫秒的警告干扰；任务用量大数字增加“万”显示。
- 增加手工参考字典及官方翻译种子，写入数据库，按批次提供参考；不做自动词库学习。
- 云端上传的人工精翻与 AI 类别只作标记，不强制重新 AI 翻译；按本次上传有译文条目计算 AI 来源占比，超过 50% 禁止选择人工精翻。来源不明、外部导入不算 AI，汉化组精翻逻辑保留。

## 安装与升级

1. 完全退出游戏，备份现有 `!Translation_AI_Pack`（包括数据库、译文与任务状态）。
2. 解压后将完整的 `AI_TranslationCore` 文件夹复制到游戏 `Mods` 目录，替换原测试版目录。
3. 仅启用一个 ATC：停用 Steam 工坊正式版及其他旧测试/开发版，再重启游戏。
4. 本包仅带 1.6 运行文件。官方包 ID 保持 `Auto.AITranslation.Core`，不能同时启用工坊同 ID 版本。

本包不包含测试存档、用户配置、API Key、数据库、聊天记录或其他群友 Mod。

## 测试状态与已知限制

- 当前源码编译打包；本包未执行自动测试或整包游戏验收。编译成功和文件一致性不代表业务功能测试通过。
- 本次手工测试截图显示 Radius UI - Colonist Bar 的 XML 设置和一组 DLL 悬停按钮已能显示译文，不代表所有 Mod 或条目完成验收。
- 短词仍可能缺少语境、译错。按钮文字与悬停说明尚未建立通用对应关系，不能承诺自动修正 Jump/Bio 等歧义。
- Token 估算仍是粗估，30% 为预算余量，尚未完成真实调用数据拟合，也不保证覆盖异常重试。
- 技术字符串用途证据和部分运行时语言启发式仍需继续检查，不能将本次字典键修复视为全部技术字符串问题已解决。

建议分别验收 XML 与 DLL 的分析、复核、翻译、已有译文跳过和热重载，并提供操作时间、条目 ID、截图与日志。调试记录分享前请确认未包含个人凭据。
