# AI 智能汉化网络 V4.5 内测版说明

发布日期：2026-09-07  
适用范围：V4.5 内测包、RimWorld 1.6 测试环境  
状态：内测，功能与界面仍需游戏内人工验收

## 版本定位

V4.5 将翻译流程从旧版扫描产线升级为可独立执行、可查看进度、可中断续作的工作流，并统一管理 XML、DLL、云端译文和用户手动修改。数据库保存条目状态与译文，生成包负责向游戏提供可加载文件。

## 主要更新

### 1. 三步翻译工作流

- 【分析】负责 XML／DLL 本地分析，默认跳过已有有效结果；【强制分析】才会重新生成。
- 【AI 复核】只判断条目是否需要翻译，已有复核结果直接跳过。
- 【AI 翻译】只翻译有效分类为“需要翻译”且没有有效译文的条目。
- 当前语言尚未完成首次译文状态同步时，真实 AI 翻译会在开始翻译前自动同步一次；已有同步记录时不会重复执行。只读【试跑】仍不会写入同步状态。
- 【一键翻译】通过确认窗口依次执行“分析 → AI 复核 → AI 翻译”。普通步骤失败会保留已完成结果并尽量继续其他可执行步骤；用户取消则停止后续步骤。
- 任务区显示当前范围、Mod／条目进度、成功、失败和剩余数量，避免把有限重试误解为死循环。

### 2. 译文来源与重复任务控制

- 固定覆盖优先级为：手动译文 > 第三方人工译文 > Mod 原生译文 > 云端译文 > 本地 AI 译文。
- 已有有效译文不会再次交给 AI，包括云端译文。
- 翻译失败不会无限自动重试。并发或频率限制仅执行有限退避；格式、占位符和不可用结果会记录明确失败原因。
- 已完成 AI 复核的条目不会重复复核。译文编辑器支持清除单条复核结果，也可按 Mod 清除 AI 复核、手动分类或两者。

### 3. 占位符保护

- 请求前将 `[PAWN_pronoun]` 等受保护占位符映射为数字标记，提示模型只在对应位置原样放回标记。
- 返回后恢复真实占位符，并在本地校验占位符的身份和出现次数。
- 占位符被翻译、缺失、新增、重复或无法恢复的结果不会写入正式译文。

### 4. 译文编辑与热重载

- 译文编辑器统一显示 XML／DLL 条目、本地分析、AI 复核、手动分类、译文来源和失败原因。
- 保存或删除手动译文后，可在编辑页直接使用黄色【热重载】。
- V4.5 热重载不再只读取现存文件：它先按数据库中的全部有效结果重建 XML 与 DLL 输出，再加载到游戏。
- 热重载不依赖 Mod 勾选，不执行分析，也不调用 AI；任务详情按条目显示重建进度。

### 5. DLL 硬编码 UI

- 【DLL UI 临时采集】与【应用已保存的 DLL UI 译文】改为两个可独立启停的并列设置，可同时开启或同时关闭。
- 临时采集只记录未被定向译文替换的界面原文；开启采集不再卸载已有翻译补丁。
- DLL 分析会按 RimWorld 当前生效的 `LoadFolders.xml` 内容目录收集程序集，并可通过 MVID 识别被影子复制到 Mod 目录外的已加载程序集，避免版本化目录或运行时加载路径导致错误的“DLL 0”。
- 临时采集补充 Unity `GUI.Button` 与 `GUI.Box` 的字符串／`GUIContent` 入口；定向补丁同时支持构造函数中的字符串候选。
- 遗留拦截器缓存单独标记为【遗留 UI 缓存】，不再与工作流数据库、DLL 采集证据或定向 DLL 译文混为一谈。
- 清理遗留缓存、修复旧译文格式、恢复最近备份等危险操作增加二次确认。

### 6. 设置页与 API 配置

- 设置页按章节统一样式；所有章节默认收起，并记住用户展开状态，包括重启游戏后。
- 【当前语言（Language）】置于常用设置首位。目前先稳定简体中文界面；该选项同时决定 AI 和云端译文的目标语言。
- API 卡片采用三级标题和双列布局，模型刷新与测试连接收进对应行。
- 单次最大输出 Token 支持“个／K／M”显示单位，切换单位时自动换算显示值，底层 Token 总数不变。

### 7. 云端翻译

- 云端列表和批量操作统一面向当前游戏已加载的 Mod／DLC。
- 最佳可用译文按“汉化组精翻 > 人工精翻 > AI 译文；同类取最新”选择。
- 下载、上传等批量网络操作在发出请求前显示实际队列和二次确认。
- 云端下载后重新同步文件状态，并恢复数据库中优先级更高的手动译文。

## 升级与使用提醒

- 测试版与 Steam 工坊正式版只能启用一个。使用测试包时先停用工坊版、旧版和其他开发版；切回工坊版时先停用或移走测试版，并重新启动游戏。
- 更新前建议备份 `!Translation_AI_Pack`，其中包含数据库、生成译文和任务状态。
- 直接编辑生成 XML 后，应先在工作台点击【刷新状态】；否则云端下载可能覆盖尚未同步的修改。
- 首次真实 AI 翻译不再要求用户预先点击【刷新状态】；程序会按需自动完成首次同步。外部修改译文文件后仍应手动刷新。
- 目前“当前语言”尚未实现全界面多语种即时切换。V4.5 先以简体中文的功能、布局和文案稳定为目标，其他界面语言将在简中稳定后统一补齐。

## 快速开始是否需要更新

需要。旧 V4.2 快速上手仍描述旧设置布局、旧工作台行为和“只重新读取文件”的热重载，且没有说明复核跳过、分类清除、占位符保护、DLL 两项独立开关和数据库重建输出。因此 V4.5 随包提供重新编写的《快速上手与常见问题》，不沿用只改版本号的旧文本。
