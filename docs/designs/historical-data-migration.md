# 历史数据迁移

文档 ID：ATC-DES-005  
状态：当前基准  
最后更新日期：2026-10-09

## 已确认范围

- 入口：翻译工作台现有【管理】菜单内【迁移历史数据】，不新增外部按钮。
- 不预扫描文件或 Mod 总数，不显示百分比或预计时间；后台逐个 Mod 处理，显示当前状态和已完成数量。
- 迁入译文全部记为 AI 来源，参与上传 AI 占比计算；仅补缺，不覆盖已有译文，不删除历史文件，不调用 AI。

## 源码依据与当前实现

旧版 XML 在生成包 `Languages/<语种>/Keyed` 和 `DefInjected/<Def类型>` 下，文件名前缀为 Mod 包 ID 将点替换为下划线。Keyed 原格式还带源文件名。XML 保存条目键和译文，没有保存历史原文或原文哈希。

目前迁移处理当前目标语种、已启用的可翻译 Mod。缺少有效分析时复用新版 XML 本地分析；按生成路径、旧 Keyed 源文件名及条目键匹配，存在重复键、包名前缀冲突或多个对应条目时不猜测。格式检查仍保留。历史原文缺失的标记与导入条目 ID 保存于本次 WorkflowRuns.result_json，汇总报告明确提示未核对历史原文；尚未添加编辑器单条标记。

每条入库由 SQL 条件再次保护已有译文，成功写入才统计导入数量。逐 Mod 将报告保存到 WorkflowSettings 的独立 history-migration-report 记录，即使取消也保留已导入条目 ID 与历史原文未核对的说明。停止保留已入库内容，可重复执行。原文件保持不变，迁移不热重载，用户随后使用现有【热重载】。

旧 `UI_Hardcoded_Cache.json` 只有语种/原文到译文的映射，缺少 Mod 和调用定位；本次保留原文件并在报告说明未迁移，不自动赋给所有同文 DLL 条目。旧忽略缓存不导入新版分类。
