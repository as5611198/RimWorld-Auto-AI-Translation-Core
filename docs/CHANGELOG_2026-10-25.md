# 2026/10/25 更新：翻譯修復與載入流程改善

本次更新著重於既有譯文的修復與套用、模組掃描準確度，以及批次 XML 的使用穩定性。

- **新增翻譯檢查與修復**：檢查 ATC 翻譯包中的失效路徑與欄位問題，修復能確認的項目，重新套用並驗證結果。修復沿用既有譯文，不呼叫 AI 翻譯服務，也不消耗 API 額度。
- **提前啟動翻譯注入**：已驗證且未變動的譯文，會優先接入遊戲原生第二輪語言注入，讓後續初始化可直接讀取譯文，並略過後段重複套用。首次修復、有變動或資料尚未準備好的情況，仍在載入畫面完成必要的驗證與套用後才顯示主選單；總啟動時間仍以實際環境為準。
- **避免重複全量修復**：完成修復後保存檢查基準；翻譯檔未變動時，重開直接套用現有翻譯。新增或更新模組本身不會因此再次執行全量修復。
- **新增增量修復流程**：翻譯任務產生新內容後，只處理受影響的模組與變更項目，避免每次都重新檢查整個翻譯包。
- **保留無法安全修復的譯文**：模組停用、內容不存在、譯文衝突或套用失敗時，保留原譯文、來源與原因，並區分「已修復」「暫不適用」與「需確認」，方便後續追查。
- **改善修復進度與結果視窗**：主選單的手動修復可等待目前作業結束後自動開始，縮小視窗仍會繼續執行；改善重複進度視窗與結果反覆彈出的問題。
- **加強翻譯套用穩定性**：處理失效欄位、清單索引及單筆套用例外；準備注入時若翻譯檔正在更新或暫時被鎖定，保留原請求並延後重試，避免漏掉尚未完成的套用。
- **改善模組文字掃描與狀態判定**：補強跨模組 XML 繼承、版本目錄及條件式內容的辨識，改善未解決項目的來源比對與漢化包排除，減少漏掃與誤判。
- **新增「勾選未翻譯」**：可一次勾選目前搜尋結果中尚未翻譯的模組，保留原有選取，並排除原版、DLC、黑名單與漢化包。
- **修正批次 XML 匯出／匯入問題**：改善較長路徑下的暫存檔寫入，並支援數字開頭的 Def 翻譯鍵，避免匯出失敗或漏掉內容；同步修正匯入、儲存及重新掃描的讀取流程。
- **新增分頁使用教學**：依第一次使用、翻譯設定、全域工作台與雲端共享整理操作說明，提供功能捷徑。首次開啟設定時顯示一次，之後可從各頁的教學入口重開。

以上更新同步提供 RimWorld **1.5、1.6、1.7** 版本，並補齊相關多語系介面文字。
