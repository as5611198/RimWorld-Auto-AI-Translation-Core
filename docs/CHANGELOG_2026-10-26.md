# 2026/10/26 更新：啟動翻譯套用優化

本次更新改善翻譯套用的啟動順序，減少進入主選單前重複處理整包翻譯造成的等待。

- **接入遊戲原生語言注入流程**：已完成驗證且未變動的譯文，優先在原生第二輪語言注入時套用，讓後續模組初始化直接讀取翻譯後的內容。
- **修正啟動時重複整包注入**：修正部分載入環境下，ATC 已提前完成注入，先前排入佇列的作業卻仍在最後重新套用整包翻譯的問題。
- **後段只補套晚建立的欄位**：部分模組會在較晚的初始化階段才建立文字欄位。現在只補試先前尚未可用的項目，避免連已成功套用的內容一起重跑。
- **保留自動更新翻譯功能**：更新後清除舊翻譯、重新翻譯及新譯文的增量套用仍正常運作。實際產生新內容時，不會因啟動注入已完成而略過更新。
- **保留驗證與失敗保護**：首次修復、翻譯檔變動或資料尚未準備好時，仍沿用原本的驗證流程；無法安全套用的譯文與來源紀錄會保留。
- **減少啟動後的記憶體保留**：套用完成後釋放完整的準備資料，僅保留判斷是否需要再次套用的必要資訊。

## 本機實測

在 RimWorld 1.7、同一份 **714 個模組**清單下，比較修正前後兩次啟動紀錄：

| 項目 | 修正前 | 修正後 |
| --- | ---: | ---: |
| 啟動報告中的到主選單計時 | 205.66 秒 | 159.94 秒 |
| 最後翻譯載入階段 | 49.28 秒 | 2.21 秒 |

本次到主選單時間縮短約 **45.7 秒（22%）**。日誌確認主要翻譯已在原生階段套用，最後僅補套 75 條晚建立的 Def 翻譯，沒有再次整包注入。實際改善幅度會隨硬體、模組清單、快取與翻譯檔變動情況而不同。

本次改動同步提供 **RimWorld 1.5／1.6／1.7** 版本，三版各通過 534 項離線整合檢查；上述實機效能數據來自 1.7。
