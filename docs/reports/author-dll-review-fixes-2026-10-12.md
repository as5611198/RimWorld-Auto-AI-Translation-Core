# 原作者 DLL 审阅问题修复记录

| 问题 | 当前源码处理 |
|---|---|
| UI 观察覆盖用途冲突 | 保留冲突及非 UI 反证，DLL 分析版本更新 |
| 字符串替换影响程序逻辑 | 在原方法的已识别显示调用前保存参数，只替换字符串显示参数，再按原顺序装回；原字符串局部变量不变 |
| 逐条雜湊 DLL | 单轮程序集哈希缓存、方法解析/指纹/指令缓存 |
| 超过清单上限撤掉全部译文 | 删除条目数与文件大小上限；先准备后替换，应用失败尝试恢复旧清单 |
| 长原文重复翻译和更新后定位改变 | 接入历史译文精确查询、来源快照与新位置写入；同页长文本合并请求 |
| 原文语种缺失 | 优先使用显式原文语种；缺失时按已确认的字形规则识别，纯汉字日文也按中文门槛处理 |
| 其他语言门槛 | 已采用并接入：空白分词语言 >3 词、日文 >6 字符、泰文 >8 字符；中文简繁 >3 字符，字符计数保留标点和空白 |
| 依赖交付 | 依赖说明已写入标准文档，1.5 项目补 Cecil 引用；未生成二进制文件 |
| UI 采集、大型 DLL 分析开销 | 暂缓 |

复用来源通过待写文件操作中的快照与译文完成事务一起保存，取消或写失败保留原有恢复路径。数据库迁移 20 新增快照列和原文哈希索引；这不是数据库已在本机完成升级的证据。

字形识别覆盖拉丁、西里尔、韩文、阿拉伯、希伯来、中文、日文和泰文。词计数按连续空白切分非空项，没有术语或完整句子例外。未支持的显式语种、无可识别文字及不能归入同一计数规则的混合文字保持逐位置翻译。门槛同时用于历史译文查询与当前页请求合并；原文、标点和目标语种仍须精确匹配。

注入位置规划仅识别受支持的显示函数、普通字符串参数、无歧义的直线局部变量流。字段、TaggedString/GUIContent、分支汇合及未知流向尚不覆盖，不能宣称所有 DLL 译文都已能显示。旧格式 manifest 可以读取，缺乏可靠显示参数的条目记录原因。

静态审阅着重参数栈顺序、实例接收者保留、取消、待写恢复、来源分类、逐候选输出和旧清单恢复。尚需用户授权后的编译及人工验收；当前结果仅为静态判断。
