# 独立模型工作流静态复审

日期：2026-10-08。执行：独立 agent，GPT-6 Astra。没有修改业务源码，没有编译、测试、游戏操作或模型 API 验证。结论来自当前工作区的静态调用链，不能作为运行验收结果。

## 确认发现

### P1：读取失败被当成原生译文来源消失

触发：同一提供方 Mod 的语言目录中既有正常译文 XML，也有非空损坏 XML 或不可读取文件。

证据：`NativeTranslationCatalog.cs:143–177` 任一文件异常会丢弃本轮整个 Mod 的 entries 并标为 Failed；`WorkflowRepository.NativeTranslations.cs:200` 只返回 Completed；`WorkflowAnalyzers.cs:1402` 无条件调用 RemoveMissingExternalTranslations；`WorkflowRepository.cs:1987` 清空未检测到的现有原生/第三方译文并标 SourceMissing。后续 AI 筛选允许这些条目重新翻译。

后果：不仅丢掉本轮其他有效文件，还可能清除历史已确认译文，破坏已有译文保护。

修复建议：逐文件隔离失败，成功文件正常匹配；失败范围不能当成确认来源已删除，不清空相应历史有效译文。原生读取失败继续后续流程的业务约定保持。

### P1：取消同步后文件缓存先行更新，下一次漏掉未入库的修改

触发：已有完成同步代次，用户手改译文文件；刷新在文件扫描后、完整发布前取消或失败；再次刷新。

证据：`TranslationFileSynchronizer.cs:156` 提前 ReplaceTranslationFileCache，而完整发布到 `:670` CommitSynchronization 才发生。下次扫描 `:217–228` 因缓存命中令 contentChanged=false；`WorkflowRepository.cs:1533/1551` 只核对 ChangedTranslationFiles 路径，未补查未完成代次。

后果：磁盘人工修改可能一直不入库；随后热重载按旧数据库重建，可能覆盖该修改。

修复建议：文件缓存与完整同步代次共同发布，或者保存未完成变化路径，在取消/失败后继续重查。

### P2：首次同步弹窗遮挡停止按钮且自身不能取消

证据：`Window_ModCatalogSync.cs:33/104` 吸收窗口外输入，运行期间没有停止或关闭按钮；等待既有后台任务的循环也没有本地取消令牌。

后果：长时间同步或等待时，用户无法操作底层工作台停止按钮，与任何活动任务都可停止的设计不一致。

修复建议：提供弹窗停止入口；等待阶段只取消自己的等待，真正执行阶段针对自己的任务请求取消，避免误停其他任务。

## 其他复核结论与边界

- 公共 RunExclusiveAsync 的后台搬迁未发现确定的 Unity 主线程回归：模型请求创建、Memory Drop 和 DLL 应用仍有主线程调度。
- DLL 指纹与分类使用同一观察快照，采集和文件分析不互斥，方向成立。
- 真正的候选分析失败停止一键 AI，与原生读取失败继续流程已区分；不能通过恢复整批中止来掩盖来源保护问题。
- 已核对核心 AI 候选筛选、编号响应检查、校验、待处理文件操作及网络取消等待，未确认其他确定缺陷。
- 未穷尽所有供应商协议、全部迁移、XML 继承和 DLL IL 分析规则。取消后脱离主任务的后台刷新需要专项核对，本次不作为已确认缺陷。

以上记录为修复前的发现，不撤销前一轮已做的修复，也不声称整个版本可交付或验收通过。

## 2026-10-09 源码修复记录

1. 原生译文逐文件隔离读取异常。成功文件入库并参与匹配；有失败文件的扫描记录为 Partial，不作为完整缓存复用。当前启用提供方的 Failed/Partial 状态同时保护缺失清理和替换入口：原文哈希仍相符的已有外部译文，不因本轮未读到原来源而被清空或改成其他来源。Partial 中同一 package/file/key 的成功读取仍可更新；后续完整扫描恢复正常来源选择。该保护按提供方保守保留，不把失败来源的旧条目重新匹配到新原文。
2. 文件扫描只生成内存缓存快照；译文变更、观察条目、文件缓存、完整同步代次在 CommitSynchronization 的同一事务中提交。循环和提交前检查取消，失败或取消不提前发布缓存。
3. 首次同步弹窗提供停止按钮，独立取消令牌贯穿等待和自身同步。停止等待不会取消其他任务；自身同步未完成时事务回滚，结束后可重试或关闭。

独立 agent 的修复复审确认第 2、3 项静态接通，并指出第 1 项的替换入口遗漏；上述来源保护已进一步补到该入口。再次复审确认该降级覆盖路径已封住，未发现确定的调用或类型错误，三项发现均已从静态实现上修正。只进行了代码、SQL 和调用链静态阅读，未编译、部署、运行测试或启动游戏。
