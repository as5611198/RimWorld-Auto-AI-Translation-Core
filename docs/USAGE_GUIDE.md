# 使用教學

適用 RimWorld 1.5／1.6／1.7。操作分頁依序為「翻譯任務、翻譯設定、全域工作台、雲端共享」。首次開啟本模組設定時會自動顯示一次分頁教學；之後可從每頁上方的「使用教學」重開。教學下方有對應功能捷徑。

## 第一次使用

【先選擇你的使用方式】
想直接使用現成譯文：到「雲端共享」選語言、搜尋模組並下載；使用雲端翻譯包不需要自己的 AI 金鑰。
想自行翻譯：先到「翻譯設定」完成供應商、金鑰、模型和目標語言設定。

【第一次自行翻譯】
1. 確認目標語言。供應商、API 網址和金鑰須屬於同一服務或方案。
2. 自訂 OpenAI：填好網址與金鑰後，手動按「重新獲取模型」，或直接手填模型 ID。
3. 按「測試連線」。成功後，回到「翻譯任務」先選一個小模組試譯。
4. 查看進度、產線日誌與完成結果，再決定是否翻譯更多模組。自行翻譯可能消耗服務額度。
5. 檢查遊戲內文字。部分畫面可能需要重開視窗或重新進入遊戲才會刷新。

想調整已完成的譯文：使用「全域工作台」。想一次交給外部工具翻譯多個模組：使用工作台的「批次 XML 匯出／匯入」。

## 翻譯設定

【基本設定】
在「翻譯設定」選擇目標語言，加入並啟用一組翻譯 API：選供應商、填對應金鑰及模型，必要時填自訂網址，再測試連線。
Custom_OpenAI 可接 OpenAI 相容服務。服務若不要求金鑰，可留空；需要驗證的服務仍須有效金鑰。填寫完成後手動重新取得模型，清單不支援時可手填模型 ID。
MiMo 的 Token Plan 與按量方案請使用各自控制台提供的網址和金鑰。Player2 請使用其本機協議及 Game Client ID，模型由 Player2 應用程式管理。

【思考模式：每組 API 的進階設定】
自動（推薦）：一般翻譯能關就關，審查 Agent 保留思考。
盡量關閉：可關閉的模型會關閉；必要思考模型維持可用的最低程度或服務預設。
啟用思考：支援時開啟，可能增加等待時間與用量。未知模型／轉接站會保留服務預設，請查看設定下方的說明。
翻譯 API 和審查 API 各自保存選擇。

【額外翻譯要求】
按「進階：自訂翻譯要求…」，例如填入「使用台灣繁體中文；人名保留原文」。最多 4000 字元，可預覽完整提示詞，或清空還原；按儲存才生效。
只影響後續一般 AI 翻譯，不影響審查 Agent 或 DeepL，也不會自動重翻既有內容。內建的格式、順序、變數與標籤保護規則仍保留。

【審查與連線問題】
審查 Agent 用來判斷模糊欄位是否適合翻譯，本身不產生譯文。初次使用可先維持關閉；需要時再配置獨立 API 與呼叫／用量限制。
連線失敗時看左上角錯誤摘要；可手動查看或複製診斷，不需要開發者模式。先核對網址、方案、金鑰與模型；不要只憑模型清單失敗就判定翻譯不能用。

## 全域工作台

【搜尋與修改譯文】
進入「全域工作台」後搜尋模組或文字，選模組、分類與條目，再修改譯文。檢查完成後按「儲存並套用」；編輯框內的草稿不等於已儲存。
可使用全域搜尋定位不同模組的文字，或用批次取代調整一致用語。修改時保留原有變數、格式參數與標籤。

【一次處理多個模組】
「批次 XML 匯出／匯入」可多選模組、匯出原文，交給外部編輯器或翻譯工具後再匯回。下方是完整操作步驟。
「一鍵打包導出」則用來輸出已完成的翻譯包。
操作批次編輯前，先等翻譯任務完成或停止，避免同時修改同一份內容。

【V4.2 BETA：批次 XML 匯出／匯入】
1. 先設定目標語言，再進入「全域工作台 → 批次 XML 匯出／匯入」。
2. 搜尋模組名稱或 ID，勾選多個模組；「全選目前清單」只會選取目前搜尋結果。清單顯示已啟用且有可處理來源的模組。
3. 按「匯出原文 XML」。每次會建立新的批次資料夾並自動開啟，依模組與分類分開存放。
4. 用編輯器或外部翻譯工具修改 XML 的文字內容。保留鍵名、格式參數、資料夾結構與批次根目錄的 manifest.json。
5. 回到批次視窗，按「預覽匯入變更」。若重開遊戲或移動資料夾，可用「選擇已有批次」或貼上批次根目錄路徑。
6. 查看各模組的變更、未變更、略過、缺少檔案與錯誤數量。預覽不會儲存；確認後按「儲存並套用」。
7. 未編輯的原文與空白內容不會蓋掉已有翻譯。原文已更新、鍵名無法對應或格式參數有問題時會略過；有錯誤的模組請修正後重新預覽。
注意：「一鍵打包導出」用於輸出已完成的翻譯包；這裡的批次 XML 用於匯出原文、外部編輯與匯入。翻譯產線執行時，請先等候完成或停止，再操作批次 XML。

## 雲端共享

【下載現成翻譯】
1. 進入「雲端共享」，先選雲端清單的目標語言。
2. 搜尋模組名稱或 ID，查看可用翻譯、類型與版本資訊。
3. 選擇適合目前模組與語言的翻譯並下載，依畫面完成套用，再檢查遊戲內文字。下載雲端包不需要自己的 AI 金鑰。

【分享你的翻譯】
先完成翻譯並檢查內容，再選擇要上傳的模組或項目，填寫顯示名稱、符合實際情況的翻譯類型與更新說明，依預覽及確認畫面完成上傳。
AI 機翻、玩家精翻與漢化組精翻是不同的內容標記，請依實際製作方式選擇。批次上傳前也請確認語言與選取範圍。

【遇到版本或內容不合】
先確認雲端目標語言、模組與版本。若下載後仍有不合適的文字，可到「全域工作台」檢查並修改本機譯文；上傳前再次檢查，避免把未完成的草稿當成完成品分享。
