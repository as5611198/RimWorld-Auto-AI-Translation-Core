全自動補位翻譯 V4.2 BETA (Auto Translation Core)
支援 RimWorld Steam 版 1.5、1.6、1.7（Waylith）。請更新並啟用 Harmony；[三版本建置與部署說明](docs/STEAM_VERSION_SUPPORT.md)。

工作台支援[批次 XML 匯出／匯入](docs/WORKBENCH_BATCH_XML.md)：多選模組匯出原文，外部編輯後預覽變更，再儲存並套用。

供應商選單支援[小米 MiMo](docs/API_CONFIGURATION.md#xiaomi-mimo)，可分別設定翻譯 API 與 Policy Agent；Token Plan 可填入控制台提供的 OpenAI 相容網址與對應金鑰。

[完整使用教學](docs/USAGE_GUIDE.md)依「第一次使用／翻譯設定／全域工作台／雲端共享」分區，包含思考模式、自訂提示詞與批次 XML 操作。遊戲內第一次開啟本模組設定時會顯示分頁導覽，之後可從每頁的「使用教學」重開。

🌐 全域翻譯記憶體池 (Global Translation Memory)
完美解決「主模組」與「漢化補丁」分離的痛點！系統會在啟動時收集你所有已安裝模組的繁/簡文字，建立一個巨大的全域共用池。遇到缺漏時，優先從池中抓取（並自動進行繁簡轉換），最大限度節省 AI 呼叫額度和時間！

☢️ Defs 深層 X 光掃描 (Deep XML X-Ray)
原作者偷懶沒寫 Languages 資料夾？沒關係！本模組內建 X 光探針，能強制破解深埋在 1.6/Defs/ 等各層級目錄下的 XML 代碼，硬生生把標題 (label) 和描述 (description) 拔出來翻譯！任何英文單字都無處可躲！

📦 無痛獨立輸出 (!Translation_AI_Pack)
翻譯完成後，系統會自動在你的 Mods 資料夾中生成一個名為 !Translation_AI_Pack 的獨立模組。絕對不會修改或破壞你原本的任何模組檔案！

🛠️ 使用方法

1.訂閱並啟用本模組（建議放在載入順序較後面的位置）。

2.進入遊戲的「選項」 -> 「模組設定」 -> 找到「全自動補位翻譯」。

3.首次開啟會顯示分頁教學；可先在「翻譯設定」確認目標語言，或到「雲端共享」尋找現成翻譯。

4.自行翻譯前，在「翻譯設定」選供應商、填入對應 API Key 與模型，再測試連線。Custom_OpenAI 填寫完成後手動取得模型；不要求金鑰的本機服務可留空。進階設定可調整思考模式與額外翻譯要求。

5.到「翻譯任務」先試譯一個小模組，查看日誌和結果後再擴大範圍；AI 服務可能消耗額度。

6.完成後檢查遊戲內文字。需要修正時到「全域工作台」編輯並儲存套用；多個模組的外部編輯可使用批次 XML 匯出／匯入。每個操作分頁都有「使用教學」入口。

​
⚠️ 注意事項

1.本工具為「按需執行」的腳本，只有在您點擊執行時才會運作，對遊戲平時運作的 TPS/FPS 影響為 0。

2.本模組採用非同步運作機制，當產線執行時，您可以關掉設定視窗繼續遊戲遊玩，隨時回來查看進度即可。

3.自動生成的翻譯包僅供個人本地使用，讓您享受最完整的 RimWorld 體驗！
